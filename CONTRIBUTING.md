# Contributing to FluxFingerprint
We welcome human contributions that adhere to the project's strategic rigor.

### Forensic Reporting
All bugs and feature proposals must use the provided forensic templates:
- **Bug Reports:** Use the "Bug Report" template to provide deep failure mechanism analysis.
- **Pull Requests:** Use the structured PR template to document architectural pivots and security compliance (LC_XXX).

### Commit Standards
- All commits must be signed-off (`-s`) to comply with the DCO.
- Follow **Conventional Commits** (e.g., `feat(parser): ...`).
- AI-generated content or agentic references are strictly prohibited (LC_004).

### Git LFS Requirement
This project uses **Git LFS** to manage binary PCAP fixtures. Please ensure you have Git LFS installed before contributing:
```bash
git lfs install
```
